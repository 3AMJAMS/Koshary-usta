The floating pop over the bowl that tells the player how the last action scored.

Ink-stroked so it reads over any part of the scene — stroke, not shadow, because the stage behind it is busy. Keep the text to two or three words; this is a glance, not a sentence. `combo` pink is reserved for rhythm hits (♪) so it lines up with the meter.
