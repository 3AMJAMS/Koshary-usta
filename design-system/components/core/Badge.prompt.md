Pill tag listing what an order contained and how it scored — used in the day-end breakdown and the order recap row.

```jsx
<Badge>ward</Badge>
<Badge tone="ok">kahraman</Badge>
<Badge tone="no">moona</Badge>
```

Only three tones, and they mean exactly one thing each: neutral = asked for, `ok` = delivered correctly (green), `no` = missing or over-served (red). Do not add colours for flavour. Write the content in the counter slang when the chapter has slang switched on.
